# 功能支持范围与后续工作

下表描述当前仓库源码的功能支持范围与已知边界，不代表特定部署实例的线上状态。部署时应按实际环境分别验证 Native 研究、期货外部数据及各模型提供方。

## 怎样使用

1. 点击顶栏“我的画像”配置投资风格、负面回避清单与风险约束；每轮 Native 研究会快照当前画像版本，历史记录不会被后续改动覆写。
2. 独立期货页 `/futures?symbol=EC` 可查看 46 个主力品种的 5 年历史分位、季节性分位、14 组盘面利润、4 阶产业链传导、基本面变化、日线技术方向与机构研报原文；右侧随行 Copilot 自动感知当前品种并支持一键精读与复盘记录。

这些是可验证的基础能力，不把未采集的基本面数据包装成已经完成的深入研究。持仓量变化不等于资金净流入，连续序列不等于可交易合约，未掌握实际组合时风险状态保持未评估。

版本变更记录见 [CHANGELOG](../CHANGELOG.md)，部署要求见[发布规范](release-process.md)。
