# Prism v0.14.5 Release Log

Date: 2026-07-03
Scope: Admin system health visibility

## What Changed

- Added `/api/admin/health`, an admin-only operational health endpoint.
- Added a System Health section to the admin console with version, deployment revision, DB status, Claude CLI status, default skill status, model-key configuration count, and skill paths.
- Bumped admin static assets to `v=40` and Service Worker cache to `prism-v0145`.

## Verification Checklist

- Python syntax checks for changed backend files.
- JavaScript syntax checks for admin UI and Service Worker.
- API tests for admin-only health access and health payload shape.
- Frontend static check that the admin console loads `/api/admin/health` and renders the system health section.
