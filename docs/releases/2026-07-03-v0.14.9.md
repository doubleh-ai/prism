# Prism v0.14.9

Date: 2026-07-03

## Fixed

- Cleared legacy IndexedDB conversation cache by upgrading `prism_cache` to version 2 and rebuilding the `convs` store.
- Added post-render DOM artifact cleanup for assistant bubbles so stale cached `[object Object]` text cannot remain visible after rendering.
- Sanitized legacy SQLite fallback messages before returning `/api/convs/{id}` payloads.
- Preserved footer SVG icons when showing recycle-bin counts by using a `data-count` badge instead of replacing link text.

## Changed

- Bumped app static assets to `v=44`.
- Service Worker cache moved to `prism-v0149`.

## Tests

- Added API coverage for legacy DB message cleanup.
- Added frontend contract coverage for IndexedDB cache reset, cache sanitization, DOM artifact cleanup, and footer icon preservation.
