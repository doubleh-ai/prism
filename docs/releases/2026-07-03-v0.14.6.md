# Prism v0.14.6

Date: 2026-07-03

## Added

- Report Library: added a user-scoped saved report library for reviewing one-click A-stock analysis outputs.
- Analysis archiving: completed analysis reports can be saved into SQLite snapshots via the UI.
- Report APIs: added `/api/reports/library` CRUD endpoints and `/api/analysis/{analysis_id}/save-report`.

## Changed

- Static asset query versions moved to `v=41`.
- Service Worker cache moved to `prism-v0146` and now precaches `app.reports.js`.
