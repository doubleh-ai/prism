# v0.15.6 - Chat stream stall guard

## Fixed

- **Chat stream stall guard**: the Claude runner now emits heartbeat events and stops a silent stream after the configured idle timeout instead of leaving the UI stuck on an empty cursor.
- **Frontend watchdog**: the browser cancels a stream that receives no events for 7 minutes and renders a clear stopped message.
- **Indicator evaluation**: fixed the K-line evaluator calling the market chain factory with `await`, which caused false "cannot fetch K-line data" errors.

## Changed

- **Configurable chat timeout**: added `PRISM_CHAT_STREAM_HEARTBEAT` and `PRISM_CHAT_STREAM_IDLE_TIMEOUT`.
- **Cache refresh**: static assets use `?v=51`; Service Worker cache uses `prism-v0156`.

## Verification

- Added tests for Claude stream idle timeout cleanup, frontend stall guard wiring, and indicator K-line chain usage.
