# v0.15.5 - Astock report cleanup and fast handoff

## Fixed
- **报告对象污染**：Astock 报告会递归抽取 LangGraph/LangChain 对象里的文本，最终决策不再显示 `[object Object]`。
- **报告上下文合并**：流式节点输出会累计合并后再生成报告，减少只取最后节点导致的内容缺失。

## Changed
- **Vibe 到 Astock 更快**：从 Vibe 候选点击“分析”默认切到快速模式，只跑行情和基本面，避免误继承深度模式。
- **缓存刷新**：静态资源升级到 `?v=50`，Service Worker 缓存升级到 `prism-v0155`。
