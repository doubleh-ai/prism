# v0.21.2 个股研究地址校验

个股研究的 `ASTOCK_LLM_BASE_URL` 由管理员显式配置。此前只读取 URL 的路径，
相对地址、缺少主机、错误协议、地址内凭证和无效端口可能继续进入提供方 SDK，
导致研究在更晚阶段失败，或让 SDK 重新解释地址。

现在在创建分析图和模型请求之前检查原始配置。只接受包含合法主机及可选合法
端口的 HTTP(S) 地址；拒绝原始空白和控制符、地址内用户名或密码、查询或片段，
即使 `?` 或 `#` 后面没有内容也不接受。错误仅记录固定的
`astock_transport_invalid`，不输出地址或凭证，也不自动修改配置或改用其他执行器。
已有 DeepSeek Messages 协议不匹配检查继续使用 `astock_transport_mismatch`。

合法的自定义网关路径、路径内百分号编码、域名、国际化域名、本机服务名、IPv4、
IPv6 和非默认端口继续可用，包括显式配置的本机 HTTP 验收代理。保留原地址，
仅沿用去除末尾斜杠的规则；不追加 `/v1`。未配置地址时仍使用提供方 SDK 默认值。
认证仍由实际提供方的启动配置承担；不从其他协议复制凭证，不修改全局进程环境。

本补丁不改变研究记录归属、缓存、报告或数据库结构，也不恢复任何 Claude Code
执行、依赖或回退。v0.21.1 的固定源码保持独立，作为另行验收的恢复候选。
源码测试、候选制品及版本号不代表已通过 Linux 隔离、真实模型、恢复或生产上线验收；
这些状态必须由各自独立的实际发布记录证明。
