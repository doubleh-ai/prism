# v0.23.0

发布日期：2026-11-07

## 主要变化

- DoubleH 提供统一入口与账号，Prism 投资研究和 Work 项目日程分别导航。个人工作内容不会自动发送给研究模型。
- Work 支持个人项目、站内协作权限、任务依赖与排程估算、附件和指定成员审批；日程支持重复规则与单次例外，服务器生成站内提醒。
- Native 研究改进预算内收尾、历史结论与证据复用、数值冲突检查、期货公开资料及用户主动许可的风险摘要。新研究只使用原生执行器与直接模型 HTTP。
- 继承界面清理、中文输入法确认回车、报告阅读和引导定位修复。

完整变更见 [Changelog](../../CHANGELOG.md)。操作说明见 [项目指南](../PROJECT_GUIDE.md)、[Work](../work.md)和[期货研究](../futures-research.md)。

## 升级与验证

使用固定标签或完整提交，保留独立数据目录。升级前按[发布规范](../release-process.md)完成任务保护、加密备份及实际恢复检查，并使用独立验证的 Native 恢复版本。不要删除新表或恢复旧数据库来迁就旧代码。

源码、构建检查和部署实例的实际状态分别核对。研究模型、保存回放、Work 协作与跨设备、外部数据源和反馈处理需要各自验证；一次模型验收不能证明所有产品流程均已通过。

## 当前限制

- 邮件、短信、设备推送和外部日历双向同步尚未默认启用。
- 云端自动修复与完整功能监测仍需独立受限身份、部署和业务验收；不开放网页任意 SSH。
- 期货资料覆盖、经纪商要求、知识的语义真实性及其他模型提供方仍有边界。数据采集或历史复用不等于事实认证。

逐项支持范围与后续工作见[功能清单](../CAPABILITY_STATUS.md)。
