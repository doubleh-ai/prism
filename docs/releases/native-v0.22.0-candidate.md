# v0.22.0 功能与验证范围

v0.22.0 包含 v0.21.3 的页面及诊断修复，并增加个人任务、单次日历、期货快照和版本化研究偏好。新增功能按灰度范围提供。

## 功能边界

- 工作数据按账号隔离。任务和日程写入有幂等标识、版本冲突保护及事务内账号复核；取消保留记录。前端不持久缓存私人表单。
- 研究偏好在创建 Native 研究时固定版本；修改设置不改变正在运行或已保存的研究。缺少实际组合时，风险状态仍为未评估。
- 期货支持固定品种的公开 HTTPS 连续日线、技术及成交持仓快照。连续序列不等于可交易合约，持仓量变化不等于资金净流入。
- 基本面、库存、基差、期限结构和会员持仓仍有数据缺口。读取来源成功不等于事实已经核验。
- 服务器提醒、重复日程、双向日历同步、邮箱找回及云端自动修复未因本版本发布自动启用。

## 验证范围

离线验证覆盖合成账号、独立数据库、任务和日程幂等、版本冲突、时区与 ICS、研究偏好固定和账号隔离。浏览器合成数据验证与真实外部数据读取须分别标注。

模型研究、工具调用、保存回放，与任务、日程、偏好、期货页面属于不同用户流程。各部署实例须逐项保留验证结果；核心研究通过不表示所有新增功能或外部数据源已通过生产验收。

## 部署验收要求

1. 固定源码与不可变候选，验证 Linux 依赖环境及兼容的 Native-only 恢复版本。
2. 先在隔离数据上验证新增表、账号删除和代码回退兼容性。程序回退不得删除新任务或偏好。
3. 使用私有受控流程，保留独立停止入口、唯一生产写入者、任务保护、加密备份与实际恢复验证。
4. 使用专用普通账号核对实际版本和用户流程；真实模型请求须具备有效、有限的许可。
5. 完成相应生产用户流程后，才将该功能标记为已验证。源码合入与 CI 成功不能替代这一步。

未完成项目见 [功能支持范围](../CAPABILITY_STATUS.md)。环境配置、操作回执、故障记录和备份由部署所有者私有保存。
