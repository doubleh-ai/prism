# v0.22.0 功能候选与验收

此文描述候选源码，不是发布成功回执。包含 v0.21.3 页面及诊断修复；新增个人任务/日历、期货快照、研究偏好和本轮快照绑定。

## 已实现边界

- 工作数据按账号隔离。任务和日程写入使用稳定请求标识、版本冲突保护和事务内账号复核；取消保留记录。前端不持久缓存私人表单。
- 研究偏好在 Native 创建事务内固定；运行中修改设置不会改变原轮次。缺少实际组合时风险状态仍未评估。
- 期货只有固定品种和公开 HTTPS 日线。5 分钟缓存保留采集时间；有限并发、15 秒总时限、响应长度和数值校验，无重定向重试。连续序列不可直接下单。
- 来源工具增加上海期货、大商所与能源中心官网，继续使用原有 DNS、连接地址、TLS、跳转与体积校验；允许读取不代表数据已取得或事实已核验。
- 新页面保留反馈入口；后台自动修复、邮箱、推送及完整期货基本面未因本次改动自动启用。

## 本机验收范围

- 使用临时合成账号和独立数据库验证任务、日程、偏好、账号隔离、幂等、冲突、DST 和 ICS。
- 执行实际前端脚本与浏览器旅程：偏好保存回读，日程新增/编辑/重叠提示/刷新保留，任务截止联动，期货展示缺口及显式转入对话。
- 浏览器期货画面使用明确标注的合成数据；公开新浪日线另行只读验证，不把两种证据混合。
- 本批不使用模型凭证、不执行真实模型请求；固定合成 Provider 测试验证偏好进入实际运行提示。
- 完整回归、覆盖率、格式、候选内容检查以及远端 CI 的结果由提交和 PR 回执绑定。

## 上线前仍需完成

1. 为固定提交构建不可变候选，验证 Linux 依赖环境和可兼容的 Native-only 恢复版本。
2. 用独立身份与隔离数据验证新增表、账号删除、旧代码回退兼容性。程序回退不能删除新任务或偏好。
3. 沿私有固定控制器核对停止入口、唯一生产写入者、任务保护、加密备份和实际恢复。
4. 核对精确线上提交，使用专用普通账号验证任务、日程、偏好与期货流程。真实模型调用只使用单独有效的有限许可。
5. 完成生产用户流程后才把对应能力标记为上线；源码合入与 CI 成功不替代这些步骤。

未完成项目和下一批顺序见 [功能完成度](../CAPABILITY_STATUS.md)。
