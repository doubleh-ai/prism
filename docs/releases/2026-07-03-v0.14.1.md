# Prism v0.14.1 Release Log

Date: 2026-07-03
Scope: Admin permissions, rendering robustness, usage analytics

## What Changed

- Fixed object-content rendering so Claude JSON/SSE blocks no longer appear as `[object Object]`.
- Restricted admin management to `ADMIN_USER` by default, falling back to `admin` when unset.
- Moved the management entry from the feature rail to the lower-left footer area.
- Added an admin usage dashboard with totals and recent user activity.
- Added `sessions.created_at` migration for login/activity statistics.
- Bumped static asset versions and Service Worker cache name to reduce stale UI after deployment.

## Verification Checklist

- Python syntax checks for changed backend files.
- JavaScript syntax checks for changed frontend modules.
- API tests for admin permissions, multi-session login, release metadata, and stats endpoint.
- Server-side pytest before deployment.
- Smoke test login page, static assets, and admin stats endpoint after deployment.
