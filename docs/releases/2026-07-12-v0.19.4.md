# Prism v0.19.4

发布日期：2026-07-12

## 分析报告排版修复

风险评估、多空辩论和旧版分析报告的 Markdown 内容现在使用统一阅读样式：

- 项目符号固定在正文区域内，不会越过折叠内容的左侧边线。
- 正文限制为更舒适的阅读宽度，超长段落不再横跨整个宽屏。
- 一级至六级标题、段落、无序列表、有序列表、引用块和代码块都有明确层级。
- 嵌套列表使用空心圆点，与一级列表区分。

## Agent 标题清理

当上游 Agent 返回 `Aggressive Analyst: # 标题` 这类文本时，Prism 会移除重复的英文角色前缀，并把后面的 Markdown 标题正常渲染。报告正文不会再直接露出角色协议文本和 `#` 符号。

## 移动端

报告在竖屏手机上使用更紧凑的内边距和字号，标题与长句会自然换行，列表保持清晰层级且不会产生横向滚动。
