# Prism v0.19.1

发布日期：2026-07-11

## 本次重点

- Vibe Trading 不再只靠提示词约束研究长度，三档深度拥有真正生效的 Agent 轮次预算。
- 聚焦研究最多 6 轮，深度研究最多 14 轮，多 Agent 研究最多 28 轮；最后一轮会停止调用工具并整理现有证据。
- 研究侧栏直接显示轮次上限与预计时长，方便在速度和证据深度之间做选择。
- sidecar 改动以独立补丁保存并绑定官方提交 `d456025672ae6cff1851ba2e77ca1a8f9abdcb47`，便于升级上游时重新校验。

## 为什么需要这一版

真实聚焦研究虽然已能调用官方 Agent 和数据工具，但一次“存储产业”验证仍执行了 12 个 LLM 轮次、25 次工具调用并耗时 251 秒。原因是官方 `SessionService` 将 `AgentLoop(max_iterations=50)` 写死，会话配置无法控制循环次数；仅在提示词里写“4-6 次工具”并不可靠。

## 实测结果

| 指标 | 修复前 | v0.19.1 | 变化 |
|---|---:|---:|---:|
| 总耗时 | 251.0 秒 | 135.6 秒 | -46% |
| LLM 轮次 | 12 | 5 | -58% |
| 工具调用 | 25 | 11 | -56% |
| 总 token | 484,759 | 192,674 | -60% |
| 报告长度 | 11,220 字 | 9,058 字 | 保留完整结构 |
| 候选数量 | 5 | 5 | 不变 |

## 使用提示

1. 聚焦研究适合快速验证单一产业问题，预计约 1-2 分钟。
2. 深度研究适合多源交叉验证，预计约 3-6 分钟。
3. 多 Agent 研究会调用专业角色团队，预计约 6-12 分钟。
4. 轮次上限是安全上限，不是固定执行次数；证据充分时官方 Agent 可以提前完成。
