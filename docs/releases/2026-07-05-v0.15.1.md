# Prism v0.15.1

Date: 2026-07-05

## Summary

This release fixes three user-visible reliability issues:

- Vibe Trading now attempts real agent enrichment before falling back to the deterministic candidate pool.
- Astock analysis gets a longer configurable timeout and bypasses the local proxy for common A-share data domains.
- Chat answers are automatically saved as report snapshots so the conversation report button has a durable artifact to open.

## Operational Notes

- Static assets moved to `?v=46`.
- Service Worker cache moved to `prism-v0151`.
- Astock timeout defaults to `PRISM_ASTOCK_HARD_TIMEOUT=1800`.
- Astock data-domain proxy bypass can be overridden with `PRISM_ASTOCK_NO_PROXY`.
- Vibe agent timeout defaults to `PRISM_VIBE_AGENT_TIMEOUT=90`.
- If `PRISM_VIBE_AGENT_MODEL` is not set, Vibe agent uses the first configured model with an API key.
