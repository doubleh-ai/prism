# Prism v0.14.8

Date: 2026-07-03

## Fixed

- Hardened the live SSE boundary so already-stringified Claude CLI placeholders like `[object Object]` are removed before reaching the browser.
- Updated live chat chunk handling so `think`, `tool`, and `text` chunks are cleaned during streaming, not only when historical messages are restored from JSONL.
- Dropped empty cleaned `think` and `text` chunks to avoid placeholder-only blocks in the active assistant message.

## Changed

- Bumped app static assets to `v=43`.
- Service Worker cache moved to `prism-v0148`.

## Tests

- Added an API-level SSE regression test for object placeholder cleanup.
- Added frontend static contract tests for `ChatRender.clean` and cleaned streaming chunks.
