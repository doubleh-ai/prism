# Prism v0.14.3 Release Log

Date: 2026-07-03
Scope: Browser cache and Service Worker recovery

## What Changed

- Serve `/` and `/login` with `Cache-Control: no-store`.
- Switch Service Worker navigations to network-first instead of cache-first.
- Stop precaching HTML app-shell routes in the Service Worker.
- Force a one-time client navigation when a new Service Worker activates.
- Register the Service Worker with `updateViaCache: none` and reload on `controllerchange`.

## Verification Checklist

- JavaScript syntax checks for Service Worker, core app, chat renderer, chat, admin, and release modules.
- Python syntax checks for changed backend files.
- API tests for release metadata and admin controls.
- Static frontend tests for release Markdown rendering and Service Worker cache policy.
- Post-deploy smoke for login page no-store header, app shell version, static asset versions, release metadata, and admin stats.
