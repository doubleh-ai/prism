# v0.15.2 - Astock speed controls

## Added
- **快速/深度模式**：A 股一键分析默认走快速链路，仅跑行情和基本面两个核心 agent；需要完整上下游研判时可以切到深度模式。
- **今日报告缓存**：同一用户、股票、交易日和模式会复用已有报告，重复查看不再每次完整启动 Astock。
- **耗时元信息**：报告顶部显示模式、是否缓存、交易日、参与 agent 和总耗时，便于判断结果来源。

## Changed
- **更少等待**：快速模式把 Astock 的辩论和风控轮次降到 0，并把 `selected_analysts` 传给 TradingAgents-astock，减少不必要的慢节点。
- **缓存可控**：侧边栏新增“重新跑”选项，需要刷新研究结论时可以跳过缓存。

## Notes
- 深度模式仍保留 7 agent 全链路，适合需要完整新闻、舆情、政策、游资和解禁上下文的场景。
