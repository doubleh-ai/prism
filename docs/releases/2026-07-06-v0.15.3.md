# v0.15.3 - Vibe history responsiveness

## Added
- **即时历史记录**：生成 Vibe 计划时先创建一条 `生成中` 记录，历史列表无需等待 agent 完整输出。
- **历史删除**：Vibe 历史项新增删除按钮，对应后端 `DELETE /api/vibe/plans/{plan_id}`。

## Changed
- **异步 agent 富化**：后端先保存规则候选池版本，再后台运行 agent；完成后同一个计划自动更新为最终内容。
- **状态可见**：计划页和历史列表都会显示 `Agent 生成中`，避免误以为没有开始执行。

## Fixed
- 点击生成后历史列表空白、必须等最终结果才出现记录的问题。
- Vibe 历史不能清理旧记录的问题。
