## 使用方式与功能边界

- 新研究从“研究对话”进入，由 Prism Native 直接调用模型 HTTP API；没有 Claude Code、旧 Skill 或 CLI fallback。
- 个股新问题同样进入 Native 对话。旧个股执行链已移除，旧个股与 Vibe 只保留所属历史读取；其旧启动接口的策略拒绝是预期行为。
- 网页研究记录与证据是主要产物，PDF 不是每次问答的强制交付物。研究记录可在所属账号内检索；保存不等于模型训练或事实已核验。
- 反馈入口及处理进度属于该应用源码；匿名权限检查不能证明云端反馈处理者已配置、队列已读或自动修复已运行。
- Work、期货专用分析、更细的用户风险画像、云端模型路由与完整自治演进仍须按各自实现和验收记录判断，不随本次源码同步宣称上线。
