# v0.15.7 - Mobile and foldable layout

## Added

- **Mobile shell**: Prism now uses a bottom navigation rail on compact screens and opens mode controls in a bottom drawer.
- **Safe-area support**: input composer, bottom navigation, modals, and guide toasts account for mobile browser and device safe areas.
- **Foldable layout**: Vibe Trading, Astock reports, report library, market quote cards, and the admin console have tablet/foldable breakpoints.

## Changed

- **Sidebar toggle**: the menu button opens the mobile drawer on phones and still collapses the sidebar on desktop.
- **Cache refresh**: static assets use `?v=52`; Service Worker cache uses `prism-v0157`.

## Verification

- Added a frontend static contract test for mobile and foldable layout wiring.
