# v0.22.0 源码候选：下一代平台与 Work 个人任务

状态：开发预览，尚未部署。源码版本号不证明任何实例已更新。

完整目标、取舍与迁移见[下一代平台设计](../platform-next/README.md)。本批开始落地个人 Work 任务：显式启用工作区、创建 / 查询 / 更新、取消保留、按版本更新、固定请求去重、有限变更记录和时区校验。

`PRISM_WORK_ENABLED=1` 在隔离实例启动时开启 `/work`；默认关闭且不创建新表。当前不支持日历、提醒、团队共享、Work Agent 或模型动作，界面与 API 如实显示范围。新工作数据仍须纳入私有备份与删除政策。

更新机制不再因 Service Worker 激活主动导航窗口，旧客户端提示用户先保存再刷新。登录返回路径只允许研究根页面或 Work，不接受任意跳转目的端。

验收结果与当前限制由设计入口状态账本更新。生产切换须保留独立停止门禁、真实任务排空、固定候选、加密备份与恢复验证及兼容恢复版；本批不修改既有不可变候选或历史回执。
