# Prism v0.19.0

发布日期：2026-07-11

## 本次重点

- AStock 深度分析不再在最终整理阶段因 `investment_debate_state` 丢失而失败。
- 对话优先交付可见 Markdown 报告，并能恢复 terminal result 或已生成的报告文件。
- Vibe Trading 区分有效成功、工具失败、空结果和报告数据缺口，深度研究停止无上限工具探索。
- K 线新增常用区间、四组均线、全屏/复位、完整悬浮信息和价格参考线。
- 管理后台新增异常诊断中心，可生成不包含敏感正文的 Codex 诊断包。

## 使用提示

1. AStock 的“快速”模式仍是 2 Agent，“深度”模式为 7 Agent；首次真实分析需要等待外部行情和 LLM，完成结果会进入缓存。
2. Vibe 的“聚焦研究”适合更快验证单一问题，“深度研究”保留多源交叉核验，“多 Agent”适合范围较大的产业研究。
3. 管理员可在“管理 -> 异常诊断”查看自动发现的问题并复制诊断包，交给 Codex 或夜间演进任务处理。
4. K 线均线可独立显隐；区间切换会重新请求相应数量的数据，鼠标悬浮可查看涨跌、振幅和量额。

## 隐私边界

诊断系统只保存页面路径、版本、组件、错误摘要、脱敏栈和有限上下文字段，不保存用户问题、报告正文、密码、Cookie、请求体或模型 API Key。
