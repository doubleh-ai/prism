## 结论摘要

- **大商所（DCE）官方接口当前不可用**：所有请求返回 HTTP 412 与反自动化 JS 挑战页，
  不是 UA/Referer 校验、不是必须 POST 表单、不是本机或生产 IP 封禁。适配器保持显式
  不可用，不执行挑战、不重试、不伪造数据。**本批改用替代源**：连续行情走新浪财经
  （M/C 自 2005-01-04、P 自 2007-10-29、I 自 2013-10-18），仓单走 99期货公开序列
  （M/C 自 2005-01-14、P 自 2008-01-04、I 自 2014-04-18，单位按来源为“手”），
  基差走生意社现期表；替代源均标注为二级来源，不冒充 DCE 官方日报。
- **郑商所（CZCE）、中金所（CFFEX）、广期所（GFEX）的每日行情已接入**：CZCE
  `MA/CF/SR/FG`、CFFEX `IF/IC/T/TF`、GFEX `SI/LC/PS`；加上原有 SHFE/INE 五品种、
  本批新增的 DCE `C 玉米 / I 铁矿石 / P 棕榈油` 与扩容批次的 14 个品种，登记品种共
  **33 个**（CZCE 9、CFFEX 5、SHFE 9、INE 3、DCE 4、GFEX 3）。三家只覆盖
  “当日交易合约的收盘/结算/成交量/持仓量”，不读取会员排名、合约参数或生产基本面；
  快照中相应部分保持未覆盖，不用其他数据替代。
- **库存（仓单）已接入 24 个品种**：SHFE/INE 的 RB/CU/AU/SC/AL/ZN/NI/AG/RU/BU/NR/LU
  读官方日报（旧 JSON 2016-01-01 起、新 HTML 2025-11-18 起），CZCE 的
  MA/CF/SR/FG/TA/RM/OI/PF 读官方仓单表（txt 2017-01-01 起、xlsx 2025-11-03 起）；
  本批新增 DCE 的 M/C/I/P，改读 99期货公开仓单序列，单位按来源如实标注为“手”且不换算
  吨数。由只读工具 `futures_inventory`（品种 + 可选 `YYYY-MM-DD`）返回该品种当日仓单
  数量、日增减与来源，并登记为 `original_obtained` 行情快照文档走既有 claim 核验路径。
  覆盖不到的 9 个品种显式返回 `inventory_unavailable` 与原因：IF/IC/T/TF/TS（中金所不设
  交易所仓单库存；TS 为扩容批次新增）、SI/LC/PS（广期所仓单周报可用但本批未接入）、
  AP 苹果（现行仓单日报只披露预报仓单，未披露实际仓单）。不估算、不补零、不用东财
  聚合数据替代，也不把预报仓单当实际仓单。
- **基差（现货−主力期货）已按生意社现期表接入**：`futures_basis`（品种 + 可选
  `YYYY-MM-DD`）读取 `https://www.100ppi.com/sf/day-YYYY-MM-DD.html`，首次 GET 返回
  `HW_CHECK` 安全检查页，正文 JS 中取出 cookie 值后重放同一地址。33 个品种中 24 个能在
  表中映射（SHFE CU/RB/AU/AL/ZN/NI/AG/RU/BU、DCE M/C/I/P、CZCE
  MA/CF/SR/FG/TA/RM/OI/PF、GFEX SI/LC/PS），其中玻璃因源表现货按元/平方米、期货按
  元/吨，当期显式不可用；SC/IF/IC/T/TF/TS/AP/NR/LU 不在表中（NR/LU 因生意社不含能源
  中心品种，AP/TS 未列出）。解不开
  检查页返回 `basis_unavailable` + `reason_code: challenge_unsolved`，不估算、不换算
  单位、不用其他日期替代。
- **现货历史价格（`futures_spot_history`）已接入**：按日期区间遍历同一份生意社现期表，
  复用基差的同一 `HW_CHECK` 链路与解析器，返回来源实际列出日期的日频现货价序列
  `{date, price, unit, source, access_method}`；缺失日期不插值、不补零。24 / 33 品种
  实测可回溯（最早 2013-01-04，铜/螺纹钢/黄金/铝/锌/白银/天然橡胶/豆粕/玉米/棕榈油
  各 3,347 个观测，多晶硅自 2024-12-26 起 458 个），单位按品种显式标注（黄金元/克、
  白银元/千克、玻璃元/平方米，玻璃按来源页注 ×80 换算为元/吨）。序列登记为
  `original_obtained` 文档；样本 < 250 或首末跨度 < 1 年返回 `backtest_ready=false`
  与原因，不可用品种返回 `spot_history_unavailable` + 原因码，不编造数字。
- **DCE 近远月价差保持显式不可用**：DCE 官网 412，替代源未提供可核对的完整挂牌合约
  月份清单（新浪只提供已命名合约的行情），因此 `futures_spread` 对 M/C/I/P 返回
  `spread_unavailable` 并给出原因，不用当日行情伪造价差。
- 三家的日行情在本机与生产机均可达；CFFEX 只能使用 `http`（两端 `https` 443 均不可
  达），GFEX 的 JSON 响应取决于 User-Agent（无浏览器/应用 UA 时返回 EdgeOne JS 挑战
  页）。适配器对挑战页显式降级为不可用，不执行、不逆向、不重试。
- **上期所（SHFE）与能源中心（INE）现有数据面实测正常**；INE 原油会员排名的缺失是
  交易所按持仓量条件的披露规则，不是解析缺陷（见下文）。
- **不存在手续费抓取代码，也没有可直接使用的逐合约手续费日报接口**；本次不新增
  手续费来源，不猜测费率。

## 扩容批次（2026-11-23）：19 → 33 品种

本批在既有 19 品种之上按“郑商所剩余活跃品种 → 中金所未接国债 → 上期所/能源中心
贵金属与橡胶系”的顺序逐个实测并接入 14 个品种，登记品种共 **33 个**。行情一律沿用既有
新浪连续合约路径；有官方日报的接日报；仓单只接能从官方报表精确取段的品种；基差只接

补充观测：

- 缺失静态路径 `/robots.txt`、`/favicon.ico` 返回 404（89/90 B），说明回源可达、404 可
  穿透；数据页面才被挑战。不是端口封禁。
- 412 响应头为 `Server: ******`、`Content-Type: text/html; charset=utf-8`，并带一个随机名
  `Set-Cookie`（约 138 B，`expires` 到 2036 年）；正文含 `$_ts` 动态脚本与随机 `<meta id=...>`。
  每次响应的 SHA-256 不同。这是交互式 JS 挑战，不是静态拒绝页。
- 生产机用真实 IPv4 直连、绕开 DNS 与 CDN 仍返回同一挑战；本地与生产两个独立出口一致，
  因此**排除 IP 封禁**（若是 IP 封禁，两个独立网络不会拿到同样的挑战页和新 cookie）。
- 开源 AKShare 的 DCE 适配器同样向该地址 POST、无特殊头，说明不是本仓请求构造的问题。

### 判断

412 的真因是 **DCE 站点级反自动化 JS 挑战（挑战页带 `$_ts` 动态脚本、`Server: ******`
与随机 cookie，与常见瑞数动态防护特征一致）**。UA、Referer、Origin、X-Requested-With、
POST 表单、GET、HTTP 版本、cookie 重放全部无效；两个独立网络与源站真实 IP 直连一致，
所以不是 IP 封禁、不是 DNS/CDN 问题，也不是本仓的请求格式问题。

### 处理边界

- 不执行、不逆向、不绕过挑战；不引入无头浏览器等新依赖；不重试、不伪装数据。
- 抓取器只对 412 响应的**有界前缀（≤64 KiB）**做特征识别（`$_ts`、`r='m'`、`Server:
  ******`），命中时返回 `error_code: automated_access_restricted`、`http_status: 412`、
  `blocked_by: anti_automation_challenge`，**不回传上游 HTML、脚本或 cookie**。
- 若 412 不带挑战特征，仍按原有 `automated_access_restricted` 处理，行为不变。
- 恢复到可用需要交易所授权渠道、官方非挑战接口或持牌数据商；在这些条件出现前，DCE
  数据保持“不可用+原因”，不产生替代或推测数据。

## 原油（SC）会员排名：条件披露，不是解析缺陷

INE 的 `pmYYYYMMDD.dat` 文件本身可用，但其中没有 `sc` 行。核对官方规则页
[各品种成交持仓排名公布标准](https://www.ine.cn/reports/tradedata/dailyandweeklydata/dailyranking/decl/202405/t20240516_802555.html)：
某一期货合约收盘后的持仓量达到公布标准后才发布前 20 名会员排名，标准为
**原油 10 万手、低硫燃料油 5 万手、20 号胶 2 万手、铜(BC) 1.5 万手、SCFIS 欧线 3 万手**
（单边计算）。2026-11-20 原油持仓量约 30,659 手，低于 10 万手，因此当日不发布排名。

实测佐证：`pm20261120.dat` 的 `o_cursor` 只有 20 号胶 63 行与低硫燃料油 42 行；抽查
2026-11-19/18、2024-01-22、2022-03-15、2020-07-21 等日期同样没有 `sc` 行，而 SHFE
的 `pm` 文件也一样不含 sc。会员排名页面只提供 `pm` 一种前缀（`cjcc`/`ccpm`/`rank`/
`pm2`/`scpm` 均为 404）。因此“SC 会员排名恒缺失”是**交易所按持仓量的披露规则**导致，
不是文件解析 bug；不能把低持仓日的无排名当作获取失败，也不能用其他品种或推算数据代替。
