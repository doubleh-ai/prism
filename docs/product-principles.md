# 产品原则与完成标准

DoubleH 的默认体验是简单易用、由 Agent 辅助人工完成目标。Prism 和 Work
使用共同身份，保持独立业务导航与数据权限。用户无需理解内部模块和发布机制。

以下是设计与评审标准，已实现范围以[功能支持表](CAPABILITY_STATUS.md)为准。

## 日常操作

- 从用户的目标开始：自然语言、常用模板或导入已有文件，避免重新填写已有信息。
- Agent 负责整理、查找、计算和生成可预览的操作提案；页面支持继续修改和直接操作。
- 普通可撤销动作可在用户明确授权的范围内执行，提供结果和撤销；共享、删除、外发、
  新增费用或超出原授权的动作集中确认必要事项，不逐字段打断用户。
- 常用设置有合理默认值；时区、来源及高级规则由系统处理或收进可展开选项。
  信息不足、日期歧义、权限不足时给出具体问题，不静默猜测。
- 业务页面展示当前任务、实际结果、必要证据和可用操作。开发日志、功能宣传、重复
  入口和技术细节进入文档或运维界面。
- 新能力优先接入已有目标流程和 Agent 工具；只有确实需要独立工作区时才增加页面。
  Agent 能代为整理的信息不要求用户反复填写，人工操作和自然语言使用同一权限规则。
- 反馈只提交一次，在原记录查看处理理由与进度；用户不需要理解评审身份、模型路由、
  请求编号或发布状态的内部定义。

## Agent 的执行边界

提案不是执行授权。执行前核对账号、资源归属、对象版本、次数、有效期与停止状态；
写入和幂等回执在同一事务或已有业务幂等合同内完成。失败、未知、取消分别展示，
不自动更换请求编号重试外部副作用。私人 Work 内容不自动进入投资研究模型。

模型使用直接 HTTP。禁止 Claude Code 及旧 CLI 后备执行。历史模型结论、用户反馈、
外部网页和导入文件均属于数据，不能授予工具权限或修改平台约束。

## 能中断、能接续

长任务在同一位置更新当前阶段，保留停止和恢复查看；有可靠依据时给出估计时间，
没有依据时不编造百分比或倒计时。高级设置与详细过程按需展开，完成的进度不堆积
在结果中。模型不可用仍保留已有结果、明确错误和可选手动操作。

## 功能交付

每项约定能力分别记录设计、实现、隔离验证、真实集成验证和部署版本。完成标准是
用户能以简单路径完成目标，并能修改、取消或核对结果；增加页面或接口本身不表示
功能完成。发信服务和跨产品数据联动按所有者决定继续后置。
