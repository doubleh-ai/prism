# 数字与产业路径检查

研究助手通过明确的结论和关系工具协议登记重要证据。用户继续提出研究目标，
指标、引句、单位及引用ID由助手整理，不新增用户填写表单或业务导航。

## 结论怎样登记

`research_record_claims` 区分事实候选、计算、推断和假设。支持、反方与背景材料
只能引用本轮 `research_read` 返回的段落；引句逐字匹配，不能自行改写成原文。
数量数据保留主体 `entities`、指标 `metric`、数值、单位、币种、所属期间及
`accounting_basis`。计算只使用本轮已有的两个不同输入ID和固定四则运算。

协议不允许模型声明已核验、选择账号、提供权限、执行表达式或修改历史报告。
不完整或有冲突的资料保留为候选，不能以引用数量代替事实认证。

## 自动检查的含义

本轮最多60条结论参与有界检查。只有主体唯一、指标、口径、期间、数量单位明确，
引用结构有效的数值才可比较；事实候选还需提供支持引句。模型对这些字段的理解
仍未独立验证，所以相容只表示“按登记口径可比较”，不表示抽取和事实一定正确。

已支持明确的元/万元/亿元、吨/万吨/千克、吨/年、片/万片/亿片、个数、百分数/
基点，以及若干每吨金额单位。金额必须注明已支持币种，绝不自动折汇；吨与吨/年、
不同币种、不同指标或不同口径不能混比。日历年、季度、半年和明确ISO日期区间
可归一化；相对日期、财政年度和未知期间不会被猜成当前日期。

同主体、指标、口径及完整期间内，换算后数值不同会形成 `potential_value_conflict`。
来源可能更新、统计范围可能不同，也可能是抽取错误；助手应回查原文并说明差异。
同值、重复报道和无冲突结果都不证明来源独立或语义正确。单位、期间不支持或缺少
可比对象时给出未评估原因，不给通过分数。

`research_read` 和登记结果返回 `numerical_checks`。报告冻结时保存当时的检查快照，
旧报告与原始段落保持不变；数值差异在原有数值旁提示，没有新增推广卡或入口。
这不是自动事实数据库，也不自动更改人工复核、争议或撤回记录。

## 与既有研究比较

登记结论、读取研究账本、打开知识详情或由 Agent 读取结构化历史时，另返回实时的
`history_checks`。它按本人仍可访问的历史，在结果数量限制之前匹配明确的主体、
指标、口径、完整期间、量纲和币种。不同单位先精确归一化；无关记录和大量同值
记录不会把较早的数值差异挤出结果窗口。

每轮最多60条当前结论、80条历史差异候选、20组差异；另有限时扫描。过期、争议、
撤回、被替代的条目和已删除会话不参与复用。范围、评估时点、未比较原因、截断
和超时分别返回，未比较完整时不能当成一致。不同主体、指标、口径、期间或币种
不会被强行并为冲突，名称相似也不会自动认作同一实体。

历史差异保留当前及历史结论ID、归一化数值和原研究入口，供回查原文；不复制一份
正文索引、不跨账号检索、不调用额外模型、不改写冻结报告。新研究或复核状态变化
会影响当前读取时的提示，原报告保持当时的内容。相同数字、已复核标签和未发现
差异仍不等于独立来源认证或语义核验。

## 产业链怎样使用

产业证据图复用本人的原始支持材料和有效复核状态。存在相容口径的数值冲突时，
相关支持材料不能直接进入可串联路径；过期、争议、撤回及被替代的资料仍按既有
规则排除。与历史的同口径数值存在差异时，同样先退出可串联路径，待回查原文和
纠错；历史比较不完整也明确保留。旧结论保留以供追溯。

路径检查实际比较各环节有效期：不重叠明确标记，未知保留未知。产品标签变化
提示需要取得转换、良率或工艺证据；同名标签也不能证明规格一致。阶段、产能
分配、客户认证、替代难度和订单兑现仍需原始披露，不能仅凭路径连通推断瓶颈、
利润转移或投资价值。

仅供给维度的候选关系参与实物流转路径，替代、认证、成本和需求关系另作分析材料，
不能因为连接同一家公司就拼成供货链。缺少商业阶段、明确有效期或失效条件的关系
不进入路径；送样、验证和候选供货不会自动升级为商业量产或收入兑现。

`evidence_graph.synthesis` 为现有研究 Agent 提供五维补证清单：可用产能与已分配
订单、客户认证、实际替代与切换条件、成本转嫁与毛利、终端订单与库存。助手先复用
适用证据，再用原有 `source_find` / `source_read` 获取公开原文，登记支持和反证。
清单按当前分页范围生成，不代表全行业已调查或研究完成；最终分析须说明产品转换、
数量约束、利润兑现及需求转弱或替代改善的失效情景。沿用对话和证据页，不增加表单。

## 精度与验证边界

四则计算使用有界十进制，避免大数加法被默认28位精度悄悄舍入。重复输入、
零除、量纲/期间/币种不符和超出范围分别保留缺口；乘除的派生单位仍需复核。
超过限制的数值和引句会拒绝，不能截断后当成另一个数值或证据。

回归使用合成文本、真实账本和权限检查，包含紧挨中文文字的数字。测试与字段
检查不证明真实公告、模型语义、实际数据集成或部署完成；这些按候选版本另行验收。
