# 期货研究资料

在期货页选择品种即可查看资料；研究对话中的 `futures_snapshot` 使用同一份结果。
系统读取并整理资料，用户不需要逐项输入交易所参数。合约、会员及规则明细默认
折叠；资料不足时保留已有结果，明确哪些问题尚未回答。

本页描述 v0.23.0 候选源码，不能代替实例的来源、模型与生产用户流程验收。

## 来源与范围

| 资料 | 当前覆盖 | 日期和口径 |
|---|---|---|
| 连续日线 | 螺纹钢、铜、黄金、豆粕、原油；新浪财经公开数据 | 仅观察序列，包含换月影响，不是可下单合约 |
| 仓单 | 上期所的螺纹钢仓库、铜、黄金及能源中心原油 | 按原表日期、单位和披露范围；不等于社会库存 |
| 具体合约结算曲线、会员排名 | 螺纹钢、铜、黄金、原油 | 曲线不是现货基差；多空排名各自披露，不推断净资金流 |
| 列示合约日期、交易所参数 | 螺纹钢、铜、黄金、原油；上期所统一公开业务参数报表 | 日期与参数分别保留自身报告日；不是经纪商确认 |

合约日期与交易参数来自[上期所业务参数查询](https://www.shfe.com.cn/reports/businessdata/prmsummary/)。
其公开页面引用的 [API 定义](https://www.shfe.com.cn/images/api.js)对应：

- `/data/busiparamdata/future/ContractBaseInfoYYYYMMDD.dat`：报告日与逐行交易日、具体合约、品种、上市日、列示到期日及交割起止日。
- `/data/busiparamdata/future/ContractDailyTradeArgumentYYYYMMDD.dat`：一般及套保持仓的买卖保证金比例、涨跌停幅度。原始小数比例转为百分数，例如 `0.07` 显示为 `7%`；买卖、一般与套保分别保留。

每份报表校验实际报告日、逐行日期、合约及品种；保留官方网址、更新时间和正文
摘要。缺失比例保持未知，特殊限制提示查原公告。源文件不允许任意网址、跳转或
认证，查询和正文大小有上限。仅日期文件返回 404 时，可查两个不同的更早日期；
网络、访问和数据格式错误不会触发旧日期兜底。一路失败不会抹去其他资料。

## 怎样理解参数

交易所报表的保证金比例不是客户经纪商的实际要求，也没有核对临时公告、适当性、
自然人持仓限制或交割资格。原合约日期表注明未包含法定节假日调整，因此使用
“列示到期日”名称；不会据此认证实际最后交易日或自动改写用户持仓。

不同来源可能属于不同日期，页面和 Agent 均按各自日期引用，不能视为同时有效的
交易规则。社会库存、同日同规格现货基差、豆粕官方数据和当前经纪商规则仍有
缺口；缺少这些输入时不生成确定的基本面或可交易性结论。

个人持仓的独立许可、参考时点和风险规则见[持仓检查](portfolio-risk.md)。
用户可以通过既有对话继续核查资料，系统不会因此获得下单或账户写入权限。
