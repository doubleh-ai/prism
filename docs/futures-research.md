# 期货研究资料

在 Prism 内的“期货研究”选择品种，点击“开始研究”即可创建 Native 研究对话，
按当前选择的模型和账号偏好分析基本面、技术面与成交持仓。研究沿用现有的停止、
保存、证据和回放流程，不需要复制问题或再次发送。模型未配置、账号变化、
会话创建未确认或原研究结果未知时，不会自动重试或切换提供方。

“查看资料”只读取数据，不调用模型；研究对话中的 `futures_snapshot` 使用同一份
结果。系统读取并整理资料，用户不需要逐项输入交易所参数。合约、会员及规则明细
默认折叠；资料不足时保留已有结果，明确哪些问题尚未回答。旧 `/futures?symbol=CU`
链接定位到同一 Prism 工作区；打开链接本身不发起研究。

本页描述源码能力，新增入口归入未发布候选，不能代替实例的来源、模型与生产用户流程验收。

## 来源与范围

| 资料 | 当前覆盖 | 日期和口径 |
|---|---|---|
| 连续日线 | 螺纹钢、铜、黄金、豆粕、原油；新浪财经公开数据 | 仅观察序列，包含换月影响，不是可下单合约 |
| 全国钢铁生产供给背景 | 螺纹钢研究读取国家统计局公开的生铁、粗钢及钢材产量 | 各期保留当期、年初累计及原文同比，单位万吨；不是螺纹钢专属产量、钢厂开工率、社会库存或现货基差 |
| 全国原油生产与炼厂加工背景 | 原油研究读取国家统计局公开的原油产量、原油加工量 | 各期保留当期、年初累计及原文同比，单位万吨；加工量是炼厂原油投入量，不是炼厂开工率、成品油产量、全球供需或可交割油种产量 |
| 大豆年度供需与压榨背景 | 豆粕研究读取农业农村部 CASDE 中国大豆年度平衡表 | 保留原表市场年度、历史/估计/预测标签及各版预测；大豆压榨投入不是豆粕产量，结余变化不是期末库存 |
| 国内黄金产量与消费背景 | 黄金研究读取中国黄金协会公开统计 | 国内原料产金、进口原料产金、原文合计及黄金消费分类，单位吨；均为年初至该期累计，不是单季数据，进口原料产金不是海关黄金进口量 |
| 仓单 | 上期所的螺纹钢仓库、铜、黄金及能源中心原油 | 按原表日期、单位和披露范围；不等于社会库存 |
| 豆粕合约与仓单公开接口 | 固定协议读取与解析已实现；实际官方数据可用性仍待验收 | 访问受限、日期回显与查询日期分别记录；未取得时保留其他来源 |
| 具体合约结算曲线、会员排名 | 螺纹钢、铜、黄金、原油 | 曲线不是现货基差；多空排名各自披露，不推断净资金流 |
| 列示合约日期、交易所参数 | 螺纹钢、铜、黄金、原油；上期所统一公开业务参数报表 | 日期与参数分别保留自身报告日；不是经纪商确认 |

合约日期与交易参数来自[上期所业务参数查询](https://www.shfe.com.cn/reports/businessdata/prmsummary/)。
其公开页面引用的 [API 定义](https://www.shfe.com.cn/images/api.js)对应：

- `/data/busiparamdata/future/ContractBaseInfoYYYYMMDD.dat`：报告日与逐行交易日、具体合约、品种、上市日、列示到期日及交割起止日。
- `/data/busiparamdata/future/ContractDailyTradeArgumentYYYYMMDD.dat`：一般及套保持仓的买卖保证金比例、涨跌停幅度。原始小数比例转为百分数，例如 `0.07` 显示为 `7%`；买卖、一般与套保分别保留。

每份报表校验实际报告日、逐行日期、合约及品种；保留官方网址、更新时间和正文
摘要。交易日与发布时间分别显示：夜盘所用参数可以在前一个日历日晚间发布，
周末或休市也可能使两者相隔多日；不要求发布时间与交易日相同，也不将发布日期
改标成交易日。报告日和逐行交易日仍须匹配查询日期，不接受晚于交易日的发布时间。
缺失比例保持未知，特殊限制提示查原公告。源文件不允许任意网址、跳转或
认证，查询和正文大小有上限。仅日期文件返回 404 时，可查两个不同的更早日期；
网络、访问和数据格式错误不会触发旧日期兜底。一路失败不会抹去其他资料。

日交易快讯与会员排名分别发布。当日快讯已发布而排名日期文件返回404时，排名
单独在同一时间上限内查找最多两个更早日期，保留各次查询状态和排名的真实日期；
不将昨日排名标为今日，不替换当前所查合约，也不在报表未披露该合约时继续寻找
更旧的排名冒充当前披露。排名日期参加日度资料的日期比较。
成交量、持买与持卖三列可以披露不同数量的会员；较短列末尾的空白不导致其他列
失效，整列未披露时数量及增减保持未知，不按零手计算。中间缺行、半空字段和重复
会员仍拒绝，原表合计行不重复计入。

全国钢铁与原油生产来自[国家统计局数据发布索引](https://www.stats.gov.cn/sj/zxfb/)实际列出的
规上工业月度原文，例如[2026年9月](https://www.stats.gov.cn/sj/zxfb/202610/t20261019_1965617.html)
和[2026年8月](https://www.stats.gov.cn/sj/zxfb/202609/t20260915_1965308.html)。每次最多读取
三个固定索引页和两份不同期原文，总等待不超过6秒、每份正文不超过1MiB；不带认证，
不跟随重定向、解决访问挑战或自动重试。原文的月度、累计、官方同比和发布日期分别
保留；1—2月合并发布时保留合并期，不编造两个月。桌面与移动页面重复表须内容一致，
只采用一份，不相加。企业统计范围和历史数可能修订，不从相邻累计数差分重建当月
产量，也不以自行计算代替官方同比。这是全国规上工业供给背景，不能解释为可用于
螺纹钢或原油交割的产量、真实订单或全球供需。原油加工量单独列示，不与原油产量
相加，也不推断进口、库存或炼厂开工率；铜、黄金和豆粕的其他基本面驱动继续保留
未覆盖状态，不能用有色金属合计或其他品种的全国数据替代。

豆粕的年度背景来自[农业农村部公开索引](https://scs.moa.gov.cn/jcyj/)列出的 CASDE
原文，例如[2026年10月报告](https://scs.moa.gov.cn/jcyj/202610/t20261009_6488446.htm)。
每次最多查询三个索引页及两期报告，沿用6秒总等待和每份1MiB上限，不带认证、不重定向
或重试。保留大豆产量、进口、消费及分项、出口和结余变化，单位万吨；市场年度为10月至
次年9月。不同月份对同一年度的预测分别显示，不能视为多份产量相加；发布日不等于
预测期结束日，更不表示预测已经实现。概要沿用资料页的基本面区域，原列标签与完整
数值可展开查看。豆粕产量、月度到港、出粕率、油厂开工、现货基差和社会库存仍未由
这张表采集；不据此补造这些数值或投资结论。

黄金统计来自[中国黄金协会黄金统计索引](https://cngold.org.cn/news-333-1.html)所列原文，
如[2026年前三季度](https://cngold.org.cn/news/show-9624.html)和
[2026年上半年](https://cngold.org.cn/news/show-9500.html)。系统最多查三个固定索引页与
两份不同期间原文，总等待不超过6秒、单份不超过1MiB，不带账号、不跟随跳转或自动
重试。核对原文来源、发布日期、统计期间与标题正文数据一致性，保留正文摘要和原文
同比；按统计期间选取资料，晚发布的旧期修订不冒充最新统计期。概要沿用既有基本面
区域，分类明细默认折叠。不从累计数差分生成单季、不把四舍五入后的分类强行配平；
进口原料产金不是海关进口量，国内产销也不能证明全球供需、可交割产量或资金流向。

累计资料与每日价格、仓单各有自身期间。页面和 Native 工具使用同一快照，已有资料
不会因另一路失败而丢弃；日度来源的日期比较不把月度供给当成同日行情。资料可读取
不表示基本面已完整、真实模型分析质量通过或该版本已经上线。

豆粕适配器使用大商所公开数据协议，字段结构参考
[公开行情适配器](https://github.com/akfamily/akshare/blob/main/akshare/futures/futures_daily_bar.py)
与[公开仓单适配器](https://github.com/akfamily/akshare/blob/main/akshare/futures/futures_warehouse_receipt.py)。
协议仅向固定公开地址发送日期和品种参数，不带用户资料、账号或凭证，不跟随跳转、
处理访问挑战或自动重试。交易所返回 412 时，原页面显示限制自动读取，保留已取得的
日线和其他资料。协议适配存在不表示官方数据已取得或已上线。

该公开协议使用 HTTP，记录明确标注传输和原始内容未独立核验；不将它改标为
经过 HTTPS 验证的来源。响应回显日期与请求日期不符时拒绝；未回显时，界面使用
“查询日期”，并保留其口径。豆粕仓单只采用明确标注且唯一的品种合计，保留“手”
单位及前后数量差，不重复叠加仓库行，也不擅自换算吨数。会员排名、同日现货基差、
社会库存和经纪商要求仍为独立缺口，不从成交量和持仓量推断资金净流向。
查询参数不进入已确认的观测日期集合，也不据此认定来源同日；豆粕资料读取不扩大
组合风险的自动对价范围。带认证头或默认认证的客户端在向该公开接口联网前即拒绝。

## 怎样理解参数

交易所报表的保证金比例不是客户经纪商的实际要求，也没有核对临时公告、适当性、
自然人持仓限制或交割资格。原合约日期表注明未包含法定节假日调整，因此使用
“列示到期日”名称；不会据此认证实际最后交易日或自动改写用户持仓。

不同来源可能属于不同日期，页面和 Agent 均按各自日期引用，不能视为同时有效的
交易规则。社会库存、同日同规格现货基差、豆粕官方数据和当前经纪商规则仍有
缺口；缺少这些输入时不生成确定的基本面或可交易性结论。

个人持仓的独立许可、参考时点和风险规则见[持仓检查](portfolio-risk.md)。
用户可以通过既有对话继续核查资料，系统不会因此获得下单或账户写入权限。
