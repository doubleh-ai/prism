# Prism v0.8 — 整体 UI 重设计

**日期**: 2026-06-20
**状态**: 设计已确认，待出实现计划
**范围**: 在新「图标栏」骨架上重做整个前端 UI —— 行情面板 + 对话面板 + K 线图表 + 前端代码模块化

---

## 1. 背景与目标

v0.7 把行情能力塞进了「侧边栏两个 tab + 主区行情面板」，暴露了三个问题：

1. **不可扩展** —— 导航只有对话/行情两个 tab，加新板块（自选/选股/研报）会让 236px 侧栏更挤。
2. **侧栏在行情模式下太窄** —— 搜索 + 自选（带价格/涨跌列）放不下。
3. **K 线图丑** —— 用了美股配色（绿涨红跌），A 股用户别扭；无均线、无网格、观感单薄。
4. **对话界面偏旧** —— 全宽条纹行 + 左侧色条，信息密度高但不够现代；`app.js` 已 1755 行，臃肿难维护。

**v0.8 目标**：把导航与内容解耦，给所有板块一个可扩展的骨架；重做图表与对话界面使其现代、护眼、专业；顺带把前端代码按板块拆分。

---

## 2. 已确认决策（用户拍板）

| 维度 | 决定 |
|---|---|
| 导航架构 | **A：42px 图标栏（固定）+ 各板块独立内容侧栏** |
| K 线样式 | **样式1**：红涨绿跌（A 股惯例）+ MA5/MA20 + 涨跌着色成交量 + 十字虚线 + dataZoom |
| 图表配色 | 跟随 App 主题；亮底 `#e4e1d8`（暖灰护眼）/ 暗底 `#101114` |
| 消息排版 | **卡片式**：AI 回复独立卡片，头部带 `复制 / 重生成 / 导出报告` |
| 输入区 | **悬浮 Composer + 工具抽屉**：已选工具 chip 化，不选不占位 |
| 首页默认 | **对话**（AI 分析是核心价值，行情一键切） |
| 自选板块 | v0.8 **不做空壳**，图标栏预留扩展位 |
| 实施顺序 | **分 3 阶段**：①骨架+图表 ②对话卡片化 ③代码拆分 |

## 3. 架构：三层 shell

```
┌──────┬─────────────┬──────────────────────────────┐
│ 图标 │ 内容侧栏     │ 主区                          │
│ 栏   │ (按板块变)   │ ┌──────────────────────────┐ │
│ 42px │ 对话:236px   │ │ 顶栏(精简) 标题+宽窄+主题  │ │
│ 💬   │ 行情:300px   │ ├──────────────────────────┤ │
│ 📈   │ 会话列表 /   │ │ 内容(消息+composer /       │ │
│ ·    │ 搜索+自选    │ │   报价卡+K线+基本面)       │ │
│ (预留)│             │ │                            │ │
└──────┴─────────────┴──────────────────────────────┘
```

### 3.1 图标栏（Icon Rail）— 新增
- 固定 42px 宽，始终可见，不随侧栏折叠而消失。
- 每个图标 = 一个板块入口。当前：💬 对话、📈 行情。预留位以后加（自选/选股/研报/预警）。
- 交互：hover 显示文字 tooltip；点击切换板块；当前板块高亮（accent 背景）。
- 主题切换按钮**留在顶栏**（见 3.3），图标栏不放。

### 3.2 内容侧栏（per-panel）
- 每个板块有自己的侧栏内容，宽度可独立设置：
  - **对话**：236px —— 新分析按钮 + 会话列表（现状保留）。
  - **行情**：300px —— 搜索框 + 自选列表（价格/涨跌列放得下）。
- 切换板块时，内容侧栏整体替换（`display` 切换或重新挂载），而非叠加。
- 保留整体侧栏折叠（现有 `.app-shell.collapsed`）。

### 3.3 主区 + 精简顶栏
- **顶栏精简**：只保留「当前板块标题 + 宽窄切换 + 主题」。
- 模型选择器**移进 chat composer**（见 4.2），不再放顶栏。
- 顶栏原有的「行情」按钮**去掉**（图标栏已是一级入口）。
- 各板块共用同一个顶栏骨架，标题随当前板块变化。

### 3.4 模式系统
- `App._mode`：`'chat' | 'market'`（未来扩展）。
- `switchMode(mode)`：设置 `#appShell[data-mode]`、高亮图标栏、切换内容侧栏与主区内容、启停行情自选刷新定时器。
- CSS 用属性选择器 `#appShell[data-mode="market"] ...` 控制各板块显隐（沿用 v0.7 模式）。

## 4. 组件设计

### 4.1 行情 K 线（样式1，重做）

**布局**：蜡烛图（主轴 56%）+ 成交量（副轴 15%）+ dataZoom 缩放（内置 + slider）。
**配色（跟随主题）**：

| 元素 | 亮色 | 暗色 |
|---|---|---|
| 图表面板底 | `#e4e1d8` | `#101114` |
| 涨/红 | `#d6332f` | `#ef5350` |
| 跌/绿 | `#1f9d83` | `#26a69a` |
| MA5 | `#cf8a3a` | `#fbbf24` |
| MA20 | `#7c5fd0` | `#a78bfa` |
| 网格线 | `#d2cec3` | `#202228` |
| 轴文字 | `#8a8478` | `#706c64` |

**要点**：
- 成交量柱按当日涨跌着色（与蜡烛同色）。
- 十字线 `axisPointer: cross`，虚线。
- tooltip 显示日期/OHLC/涨跌幅。
- 主题切换时重建 option（监听 `App._theme` 或重绘）。
- 圆角卡片容器，融入各自主题底色。

**周期**：日 / 周 / 月（`period=1d/1w/1m`，沿用 v0.7 端点）。

### 4.2 对话：卡片式消息 + 悬浮 Composer

**消息卡片（AI 回复）**：
- 独立卡片：白底（亮）/ `--bg2`（暗）、`border`、圆角 12px、轻阴影。
- 卡片头：左侧 mono 小标签 `PRISM · 分析`（可含模型名）；右侧操作 `📋 复制 · ↻ 重生成 · ↗ 导出报告`。
- 卡片体：富文本（marked 渲染，沿用现有 `.bubble` 排版规则：标题/表格/code/quote chip/报告链接）。

**用户消息**：
- 紧凑 accent 气泡，右对齐，圆角 `16 16 4 16`，max-width 70%。

**回合间距**：卡片间留白 16-20px，取代 v0.7 的全宽条纹 + border-bottom。

**悬浮 Composer**：
- 圆角 16px 浮起卡片，轻阴影，距底留白。
- 顶部：**已选工具 chip 行**（仅当有非默认工具被选时显示，每个 chip 带 × 移除）。
- 中部：textarea，placeholder 引导。
- 底部操作行：`🛠 工具(N)`（开抽屉增删技能）· `模型 pill`（GLM-5.2 ▾，替代顶栏模型选择）· `➤ 发送`。
- 抽屉：弹出技能多选面板（复用现有 skills 数据 + `_activeSkills` 逻辑）。
- 快捷键：ENTER 发送、SHIFT+ENTER 换行（不变）。

**欢迎页（chat 模式空态）**：
- 居中 serif 标题 + 一行说明 + quick-ask chips（沿用现有 `.welcome`/`.qa-chip`），点击即填入 composer 并发送。

### 4.3 行情面板其余组件（沿用 v0.7，微调）
- **报价卡**：大字价格 + 涨跌额/幅 + OHLCV 网格 + 来源/时间戳 + 「问 AI」按钮。
- **基本面摘要**：PE/PB 等（baostock 提供）。
- **自选侧栏**：搜索结果（⊕ 自选）+ 自选列表（代码/名称/价/涨跌，60s 刷新）。
- **联动**：`[[quote:TICKER]]` chip 点击 → 切行情模式 + 选中；「问 AI」→ 切回对话 + 预填。

### 4.4 主题系统
- 沿用现有 `html.light`/`html.dark` + localStorage(`cl-theme`)。
- 图表在主题切换时重绘（用对应配色表）。
- 亮色底统一用 App `--bg #f9f8f5`；图表面板单独用护眼 `#e4e1d8`（比主底暗一档，区分图表区）。

### 4.5 错误/空态（沿用 v0.7）
- 搜索无结果、行情不可用（重试）、K 线为空、自选为空（引导）、加载 shimmer。

## 5. 代码重构：app.js → 4 模块

当前 `static/js/app.js` 1755 行单文件。拆分为 4 个文件，**全部挂到 `window.App` 全局对象**（保留全局，HTML 内联 `onclick="App.x()"` 无需改动，零行为风险）：

| 文件 | 职责 |
|---|---|
| `app.core.js` | init、state、`switchMode`、主题、`api()` 助手、cookie、bootstrap |
| `app.chat.js` | 流式接收、消息渲染（卡片化）、composer、技能抽屉、自动补全、quick-ask |
| `app.market.js` | 报价卡、K 线 echarts、自选、侧栏搜索、`_selectStock`、联动 |
| `app.util.js` | `esc`/`escAttr`、数字/成交量格式化、glossary、报告查看器、dom helper |

**加载顺序**（`app.html` 底部）：
```html
<script src="/static/lib/marked.min.js?v=N"></script>
<script src="/static/lib/echarts.min.js?v=N"></script>
<script src="/static/js/app.util.js?v=N"></script>
<script src="/static/js/app.core.js?v=N"></script>
<script src="/static/js/app.chat.js?v=N"></script>
<script src="/static/js/app.market.js?v=N"></script>
```
拆分原则：每个文件聚焦一个领域；共享状态走 `App._xxx`；无循环依赖（util ← core ← chat/market）。

## 6. 实施分阶段

> 阶段化降低风险，每阶段可独立部署验收。

**阶段 1 — 骨架 + 图表**（最大结构改动）
- 新增图标栏，`switchMode` 改为图标栏驱动。
- 内容侧栏 per-panel 化（行情 300px）。
- 顶栏精简（移除行情按钮；模型暂留顶栏，阶段 2 再挪）。
- K 线重做为样式1（配色表 + 均线 + 涨跌量 + 主题跟随）。

**阶段 2 — 对话卡片化 + Composer**
- 消息改卡片式（卡片头操作）。
- 悬浮 composer + 工具抽屉；模型 pill 挪入 composer。
- 欢迎页对接新 composer。

**阶段 3 — 代码拆分**
- `app.js` 拆 4 文件，逐方法迁移，行为不变。
- `app.html` 改引用顺序 + `?v` 破缓存。
