# 发布观察与受控上线流程

Prism 开源仓库保存应用、通用交付规范和离线测试。部署所有者应受限管理具体环境的运维源码、地址、服务映射、访问配置、许可与验收记录；凭证、用户数据、日志、备份及私人历史不进入 Git 仓库或公开构建产物。

本文是可移植的发布规范，不记录任何实例的部署状态，也不包含环境特定的执行步骤。文档、源码提交、绿色 CI 或网页环境标签均不能单独证明某个版本已部署。

## Native-only 发布与恢复合同

实际资格验收与发布控制的执行源码、操作测试仅在部署所有者的私有运维流程中维护。公开仓库的 `scripts/new_runtime_stop.py` 只返回退役提示，不执行主机或服务操作；公开应用测试保留 Native 业务、取消、历史及策略拒绝回归。入口退役不构成验收或发布证据。

整个 Prism 禁止依赖或回退到 Claude Code CLI，包括候选验收与恢复。依赖 CLI 的控制器、探针或恢复路径不能用于 Native-only 部署；不得靠安装 CLI、恢复旧 Skill 或打开旧开关满足门禁。

部署所有者应使用明确版本和字段类型的 **Native 发布合同**及**独立的 CLI-free 恢复合同**，绑定完整提交、产物、依赖、配置、数据兼容、任务生产者与验收证据。恢复候选须独立验收；历史记录不能覆盖源码、环境或数据的变化。合同源码和字段齐全也不等于真实验证通过。

环境专属控制源码、主机地址、许可与完整记录应受限管理；公开规范只描述可移植要求，不授予生产执行权。

## 能力与证据边界

- CI 检查格式、回归、覆盖率和依赖漏洞。候选打包流程从完整提交构建源码清单和摘要，不访问生产，也不执行候选应用。
- 应用管理员控制台可读取 PR、工作流和脱敏发布记录。控制台为观察入口，不承担部署、重启或回滚操作；独立发布记录必须在应用不可用时仍能访问。
- 部署流程须符合 Native-only 合同；实现、离线测试、实际隔离验收、真实模型验收和生产发布是不同证据，不能互相代替。
- 就绪接口仅证明本实例的基础检查通过。完整提交、来源清单、登录、核心用户旅程、模型和数据源必须分别验证。
- Native 源码包含 `agent` 持久化任务、直接模型连接、研究事件与结果保存。部署时须验证停止、后台工作归属、事件持久化、单实例重启与兼容恢复；其他执行引擎的历史记录不能替代这些验证。
- 旧个股执行的固定策略拒绝返回带明确策略标记的 503，保留使用记录，不作为服务故障诊断；其他 5xx 仍按实际故障记录。拒绝不能遗留阻塞租约。

## GitHub Actions

网站运行本身不依赖 Actions。保留 `CI` 和 `Release candidate (not deployment)` 两套工作流；列表中的多条记录是历史运行，不等于多套独立流程。候选产物保留期限和触发分支以工作流文件为准，产物不包含凭证或运行数据。

同一 PR 可以取消过时 CI，以减少重复消耗。生产写操作另行串行化，不能通过取消旧工作流来假定旧生产操作已停止。历史失败和中断记录应保留用于追溯。

## 固定候选

使用完整 Git 提交生成候选源码包、逐文件清单和归档摘要，并将产物放在 Git 工作区之外。候选只能来自该提交，工作区未提交文件不进入候选。

验证必须比对同一提交的实际对象，拒绝路径穿越、软链接、重复条目、清单外文件和摘要差异。依赖锁、额外继承包、外部引擎及工具需要各自真实清单；核心依赖锁不能代表整个部署环境。

PR 自己运行的绿色检查属于开发证据。生产晋级还需独立受信任的验证器、固定执行器与真实环境回执，不允许候选自己授权自己。

## 阶段和停止保护

| 阶段 | 要求 |
|---|---|
| 现场核对 | 记录实际服务、进程、完整修订号与源码来源；未知项保持未知，先保护未同步成果。 |
| 准备 | 在独立代码与依赖位置准备固定候选，确认加密备份、恢复验证、数据库兼容和可用恢复版本。 |
| 隔离验收 | 使用独立身份、数据副本、私有网络与资源限制，撤销副本会话，建立合成账号。验证实际进程、文件和网络隔离。 |
| 维护与排空 | 关闭新任务入口，核对所有生产者与实际任务均已排空；已受理工作的生命周期和持久化必须可证明。 |
| 切换 | 再次核对停止保护、当前现场指纹、已接受的候选和恢复证据，执行单个受控切换阶段。 |
| 内部验证 | 核对实际运行修订号、源码/依赖身份、就绪、鉴权和核心用户旅程。维护仍生效时仅是内部验收。 |
| 恢复入口 | 内部验收通过后恢复访问并复核外部入口，完成独立发布记录。 |
| 回退 | 只切回已实际验收、与当前数据兼容的代码与环境；保留失败与回退记录。 |

每个受控边界前重新检查独立停止入口、许可和实际状态。停止入口关闭、不可访问或状态未知时不得进入下一边界。用户可在不依赖 Prism 本身的独立记录和停止入口介入。

取消会阻止后续阶段，不能证明已经完成的动作被撤销。连接断开时对账同一操作的私有记录和实际现场，不能把断开连接当作远端停止。诊断失败保留失败事实，不可转写为准备或发布成功。

## 备份、恢复与数据

备份覆盖应用现场、运行数据、环境依赖和离线来源，凭证采用独立受限保存。备份需加密、验证完整性，并在隔离位置实际恢复验证；仅创建压缩包或文件存在不构成可恢复证明。

代码、配置、数据和日志保持独立。候选不得导入或迁移生产数据来做开发检查。复制的数据先撤销会话和短期工具授权，使用合成身份验收，不把真实用户历史用于模型测试。

程序回退不自动恢复数据库。任何破坏性数据恢复需要单独明确授权、影响范围和可能丢失的数据窗口，不能为恢复旧程序静默丢弃新写入。

## 原生 Agent 的额外验收

[原生 Agent 架构](native-agent-framework.md)说明当前实现与尚未迁移的能力。整个应用只允许 Prism Native 与直接模型 HTTP，不得启用 Claude Code CLI、外部 Skill 或第三方模型编排。辅助模型同样直接使用 HTTP。旧个股自动分析的模型编排、后台执行、分析缓存与辅助提取实现已移除。兼容启动接口和 `analysis_start` 固定返回 503；缓存数据、强制刷新或旧环境变量不能恢复执行。已有个股状态与报告仍可读取，个股分析按钮继续进入原生研究对话。Vibe 新研究与追问也继续返回 503，不能在发布时顺便启用。此源码变更需要重新固定候选与恢复提交并验收，不能沿用原提交的资格记录。

- 相同请求复用与原子认领，不重复发起未知用量的模型调用。
- 浏览器断开只结束读者；事件可以回放，任务结果可以恢复查看。
- 停止等待模型连接和已归属后台工作真实结束，再确认终态。
- 维护排空包含 `agent` 及其派生工作，不能沿用缺少该类型的旧资格记录。
- 重启后保留中断和未知用量，不自动重新发送原模型请求。
- 账号、会话删除与停用不会泄露历史或重建已删除内容。
- 研究日期、来源时间、证据缺口和未核验结论真实保留。
- 新增数据结构支持已实际接受的恢复版本；恢复验证须与本候选匹配。
- 历史服务只访问平台 SQLite。旧 JSONL 只能经显式离线副本导入；验证公开文本、回合数、源指纹、归属、冲突拒绝及现有 SQL/Native 锚点保留。迁移不完整时显示 `pending_import`，不能临时恢复外部目录读取。
- Native 健康检查只验证本地入口、工具与模型配置，不能把配置存在当作真实 API 验收；确认验收路径也没有旧 CLI 或备用执行器。

真实模型验收使用新获准的有限合成请求，明确目的地、内容、次数、用量与时间边界；凭证只用于相应提供方认证。离线模拟通过不表示真实 API 兼容、研究质量或生产上线已经通过。

## 发布完成的判定

反馈监测新增独立只读接口候选，认证与可写 worker 分离，仅输出有界元数据和诊断代码；
参见 [API 契约](API.md#read-only-feedback-monitoring-candidate)。它不提供修复、建议决策
或发布权限，也没有部署云端消费服务。启用前需通过私有受控流程配置独立身份，核对实际
上线版本，并验证只读读取成功、越权写入拒绝、敏感字段不出站和分页检查点。没有这些现场
证明时，继续显示“监测未接入”，不能把接口源码或健康页正常当成已监测用户反馈。

独立记录应显示固定提交、产物摘要、环境、操作者、阶段、开始/结束时间、停止状态和各类验收证据。公开内容仅保留必要的脱敏状态。

仅在固定候选通过实际验证、正常恢复访问且本轮没有回退后，标记本轮部署验证成功。失败、取消、未知和回退分别呈现，不能覆盖为绿色成功。具体执行细节与环境清单由部署所有者受限管理。
