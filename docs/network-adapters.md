# 网络适配

## 公开资料

行情、期货、指标扫描、风险估值和研究资料采集共用 `server.public_network` 的
启动适配接口。普通部署使用直接 HTTPS；隔离部署可以在开始处理请求前安装一次
适配器，分别提供同步 HTTP、异步 HTTP 和资料采集使用的 TLS 连接。

HTTP 客户端不使用环境代理、不自动跟随重定向，也不自动重试。研究资料仍由原有
解析器验证 URL、逐跳重定向、响应大小、内容类型与资料时间，保留正文摘要及
“未审阅”状态。选择委托连接时，由部署适配器负责验证目的地址、实际连接及
TLS；失败直接返回来源不可用，不能退回直接联网。

该接口不提供网页配置入口，也不授予服务器联网权限。主机、进程、文件、网络与
凭证的隔离必须由部署方单独落实并验证。普通部署原有的资料采集继续执行公开 DNS、
字面地址连接和主机名证书校验。

模型连接使用独立 Provider 通道，不经过公开资料适配器。第三方数据 SDK 的内部
联网不自动获得此接口的权限；隔离部署应明确选择支持的适配器，不能把失败解释为
空数据或静默打开任意外联。

离线模拟可以验证注入、解析、重定向、失败及关闭行为，不能证明公开来源可用、
部署已启用外联或研究质量已通过真实验收。

## Native 模型

`server.model_network.install(adapter)` 可在开始处理请求前安装一次模型网络适配器。
适配器的 `async_transport(purpose=..., endpoint=..., model=...)` 为每次调用提供独立的
`httpx.AsyncBaseTransport`。用途包括 `research`、`work_planning` 和 `auxiliary`；
部署方应只放行明确配置的用途、提供方与模型组合。

MiniMax 国内站使用独立的 `minimax-cn-m3` 目录项和 `MINIMAX_CN_API_KEY`，固定访问
`https://api.minimaxi.com/anthropic/v1/messages`；海外站继续使用自己的条目和凭证。
两者不共享默认 Key、不互相回退。套餐专用 Key 应由配置者明确提供，不能假定普通
余额 API Key 会抵扣包年额度。区域说明参见 [MiniMax 官方配置示例](https://github.com/MiniMax-AI/Mini-Agent/blob/main/mini_agent/config/config-example.yaml)。

研究和 Work 分别从原用途路由取得配置，辅助任务单独标注用途。用途信息仅用于
本机选择连接，不加入发往模型的 JSON。适配器工厂不接收 Key、问题或用户资料；
实际传输仍承担敏感模型请求，必须遵循部署方的隔离与凭证策略。

Provider 继续使用直接 Messages 或 Responses 协议。安装委托适配后，返回空连接、
配置错误或出口不可用均直接失败，不回退直连、环境代理或另一个提供方。显式传入
的测试连接也不能覆盖已安装的部署策略。未安装时保留普通自托管的直接 HTTPS。

模型网络适配不配置 Key，不修改用途预算，不授权 Work 内容处理，也不代表真实模型
验收通过。Work 仍按原流程生成预览、由用户确认后执行，并支持撤销；未知调用用量
继续保留。生产启用还需要独立验证启动配置、实际网络、提供方协议与消费者流程。

隔离部署可另外调用 `server.model_routes.install_defaults(policy)`，在启动时设置
研究和 Work 的用途配置。每项须明确模型、启用状态、Work 内容处理许可，以及单次
输出、请求数、时长和每日调用上限；配置中不包含 Key。未列出的用途关闭，不会借用
其他用途的模型。这个接口只安装一次内存策略，不写入管理员设置；已保存的管理员
设置优先，调用仍进入原持久化用量账本。Work 用户还须同意本次模型处理，写操作仍
经过预览与确认。启动配置校验失败时不继续提供模型服务。
## 模型错误诊断

模型请求失败时，Native 运行事件保留固定错误类别和 HTTP 状态。MiniMax 的
JSON 错误另提取官方公布的数字错误码，用于区分参数、模型权限及套餐额度问题。
只读取最多 16 KiB、最多 3 秒的错误内容；不保存或展示响应原文、认证头、Key
或请求内容。未知、冲突或不可解析的错误码省略，不猜测原因，不自动重试。

例如，`provider_http_error` 配合 `http_status: 400` 和
`provider_status: 2061`，表示应核对套餐的模型支持范围；单独的通用错误不能
证明 Key 填错。其他提供方及重定向响应仍不读取错误正文。
错误码含义以 [MiniMax 官方错误码文档](https://platform.minimax.cn/docs/api-reference/errorcode)
为准。诊断实现和离线测试通过不代表某台服务器已经启用或完成模型验收。
