# 公开资料的网络适配

行情、期货、指标扫描、风险估值和研究资料采集共用 `server.public_network` 的
启动适配接口。普通部署使用直接 HTTPS；隔离部署可以在开始处理请求前安装一次
适配器，分别提供同步 HTTP、异步 HTTP 和资料采集使用的 TLS 连接。

HTTP 客户端不使用环境代理、不自动跟随重定向，也不自动重试。研究资料仍由原有
解析器验证 URL、逐跳重定向、响应大小、内容类型与资料时间，保留正文摘要及
“未审阅”状态。选择委托连接时，由部署适配器负责验证目的地址、实际连接及
TLS；失败直接返回来源不可用，不能退回直接联网。

该接口不提供网页配置入口，也不授予服务器联网权限。主机、进程、文件、网络与
凭证的隔离必须由部署方单独落实并验证。普通部署原有的资料采集继续执行公开 DNS、
字面地址连接和主机名证书校验。

模型连接使用独立 Provider 通道，不经过公开资料适配器。第三方数据 SDK 的内部
联网不自动获得此接口的权限；隔离部署应明确选择支持的适配器，不能把失败解释为
空数据或静默打开任意外联。

离线模拟可以验证注入、解析、重定向、失败及关闭行为，不能证明公开来源可用、
部署已启用外联或研究质量已通过真实验收。
