# 持仓导入与风险检查

本页描述开发候选。实例需部署并完成用户流程验收后才可使用，不连接券商、不下单。

## 从已有持仓开始

在 Prism 的“研究偏好 → 持仓与风险检查”中，可以直接填写，也可以展开“批量导入”。
粘贴 CSV 或从表格复制的制表符文本，或选择 UTF-8 CSV 文件；每次最多100条、64KiB。
解析只生成预览，不保存文件或修改持仓。核对后应用到当前草稿，再使用原来的“保存并检查”。
错误不会部分导入；其他设备已更新时拒绝覆盖，保存结果未知时先重新读取核对。

必要列为 `asset_id`、`quantity`、`price`，也可使用“代码、数量、价格”等中文表头。
数量与价格使用普通十进制数，不把成本价当作当前价格。可省略币种和价格时间，使用
表单中明确填写的值；不从空白或无时区日期猜测。未采用的额外列只报告数量，不保存其内容。

证券示例：

```csv
代码,数量,价格,币种,价格时间
SH:600000,100,10.25,CNY,2026-11-03T12:00:00+08:00
```

期货还需明确类型、具体合约、方向和合约乘数：

```csv
类型,代码,数量,价格,币种,价格时间,方向,合约乘数
期货,SHFE:RB2701,2,3500,CNY,2026-11-03T12:00:00+08:00,多,10
```

这里的乘数和价格仅为计算示例，不是当前合约规格或行情。
期货代码接受 SHFE、INE、DCE 前缀和明确的四位年月，不接受连续或主力序列。
手数必须是正整数。可补充“保证金比例、规则核对时间、最后交易日、来源”列；
比例填写百分数，例如 `12` 表示12%，不从手续费、最低交易所比例或历史规则推算。
暂不支持 Excel 工作簿、期权、外汇换算或卖空证券。

## 分清资产、敞口和保证金

- 净权益＝证券账户等现金＋证券市值＋期货账户权益－负债。
  现金不再重复包含已单独填写的期货账户权益；期货权益应使用账户实际权益，
  包含已占用保证金，不仅填写可用余额。系统不能证明用户没有重复填写账户资金。
- 线性期货名义敞口＝手数×合约乘数×参考价格。名义金额不当作资产加入净权益。
  合约单位与名义金额的关系见 [CME 说明](https://www.cmegroup.com/education/courses/introduction-to-futures/about-contract-notional-value)。
- 集中度按证券标的或同一期货品种合并不同到期月的总敞口，再除以净权益。
  多空不抵消，不假定跨期、套利或跨市场抵扣。杠杆偏好按负债及总敞口检查。
- 保证金估算＝逐合约名义金额×用户填写的经纪商保证金比例，再求和。
  与独立填写的期货账户权益比较，不借用证券市值作为已获批准的抵押品。
  交易所保证金与经纪商实际要求不同；每日结算及追加保证金机制见
  [CFTC 说明](https://www.cftc.gov/LearnAndProtect/AdvisoriesAndArticles/economicpurpose.html)。

价格及快照时间须在7天内；币种不同且无明确汇率时保持未评估。期货规则需填写
近期核对时间和公开来源，缺少时不能把保证金与期限检查标为通过。填写了来源仍是
用户提供的数据，不等于系统已读取并核验原文。最后交易日按上海日期检查：已过期
需核对，缺失或临近7天须继续核对持仓期限和交割资格。

期货情景详情按每个持仓分别发生5%、10%不利变动计算损失、剩余期货权益和
固定保证金比例下的估算缺口。多头假设下跌、空头假设上涨；不是同时发生的一条
市场预测，不含对冲收益、手续费、滑点、跳空、保证金调整或券商强平规则。
缺少必要数据时不填零，不计算可开仓数量或保证可执行的止损价格。

## 让研究使用风险约束

默认不向模型发送持仓。主动选择“供新研究使用风险摘要”并保存后，新一轮 Native
研究会冻结本人当时的偏好版本、持仓版本和规则检查摘要；不自动发送持仓代码、
逐项数量、价格或原始导入文件。未评估和超限结果也会进入摘要，不能因风格激进被忽略。

后续修改或关闭该选项只影响新研究；正在进行及历史研究保留原版本，便于核查。
摘要包含财务金额，会随本轮请求交给所选模型服务商；不自动交给其他账号或 Work
助手。这不会在平台内训练或更新模型权重，所选服务商的数据政策另行适用。
完整范围见[功能支持表](CAPABILITY_STATUS.md)。
