# 资料发现与日期

用户在研究对话中提出问题，Native Agent 使用 `source_find` 找线索，再用
`source_read` 读取原文。沿用对话和证据页，不增加搜索设置或业务入口。
这两步是资料采集，不能自动把模型判断提升为已核实事实。

## 当前覆盖

| 来源 | 发现方式 | 范围 |
|---|---|---|
| 上交所公告 | 官网公告查询的固定公开 JSON 入口，按关键词、证券代码、日期和页码查询 | 一次返回一页；再次校验实际证券代码、标题和日期，不保证覆盖其他交易所或全部公告 |
| 新浪财经 | 官网滚动列表的固定公开 JSON 入口，在返回内容内匹配关键词 | 有界列表，不是全文、全时段或全网搜索；无命中不能证明不存在相关新闻 |
| 公司公告官网、其他获准来源 | `source_read` 返回页面实际存在的链接，再读取相关原文 | 公司 IR 主机由部署配置允许；不执行网页脚本、不自动遍历整站 |
| 财联社、金十等 | 继续支持获准原文 URL 的读取 | 匿名索引适配尚未完成，不借用账号、凭证或付费接口，不宣称已搜索这些来源 |

公开协议参考为[上交所公告页](https://www.sse.com.cn/disclosure/listedinfo/announcement/)
及其本站查询脚本、[新浪财经滚动页](https://finance.sina.com.cn/roll/)
及其本站列表脚本。提供方改变字段、返回登录页或拒绝请求时，适配保留错误或覆盖缺口。

## 原文、索引、期间分开

结果保存实际 URL、采集时点、索引标注日期及精度、索引 URL 和文件摘要。
索引标题与摘要仍属于搜索线索，不表示原文已读、完整正文已保存或事实已独立复核。

读取原文后，原文提供的日期元数据优先；原文没有日期时，只能复用本轮、同一 URL
实际取得的索引日期，并继续标为“索引标注”。跳转到另一 URL 不借用旧日期。
正文落款、数据所属期间、披露日期和采集时间不能相互替代；只有日期时不编造具体时刻。
索引与原文分别保存摘要，避免将索引文件摘要误写成公告正文摘要。

页面链接只是待读取的目标。链接中的年份、路径或标题不自动成为发布日期；
未获准的主机、带凭证的 URL、私有地址及脚本链接不会提供给后续读取。

## 开发合同

`server/agent/discovery.py` 定义封闭参数、固定入口、结构校验、日期匹配和覆盖范围。
单次最多两个索引请求、八秒总预算，一页结果最多二十条；没有自动重试或循环爬取。
仅指定证券代码时默认查询上交所，不用无关新闻填充结果。

`server/agent/sources.py` 复用公网 DNS 校验、固定地址连接、主机名 TLS 校验、有限响应
和跳转检查。保留或私有 DNS 地址、异常编码、含糊 JSON、越界响应及认证错误明确失败。
不读取 Cookie、搜索密钥或环境代理；原始网页、JSON 与用户输入均不授予执行权限。

工具属于真实研究任务，取消不会把仍运行的解析或网络工作伪装成已结束。同一调用
编号的结果未知时不重新抓取。返回结果登记到账号所属的研究账本，保持历史与纠错链。
统一调用历史保存状态和所属研究入口，不重复保存查询文本、来源正文或历史知识内容；
刷新后仍可打开原研究，其他账号与已删除会话不能读取这些记录。
统一历史登记适用于本候选起的新调用；旧研究与原对话保持原样可读。

离线协议、模拟用户流程、真实来源连通性和部署验收分别记录。某个请求成功或 CI
通过，不能替代其他部署网络、来源、用户流程或研究质量的验收。
